One network. One reward. No search.

A neural network with a memory learned to solve the cube by trial and error. Every move costs −1, so it learned to use few moves. Nobody showed it a solution.

−1per move: the only reward
12quarter turns to choose from
16,384cubes practised at once
1 → 30scramble moves: easy cubes first
8.9 Mweights, with an LSTM memory

How it learns

  • Recurrent PPO. All cubes play 16 moves, then the network is updated on what happened. This repeats 5,270 times.
  • Easy cubes first. It starts with cubes one move from solved. When it solves half of them, harder cubes come in.
  • A move limit. An attempt ends when the cube is solved or the limit is reached.
  • No search. To solve, it looks at the cube and plays its best move, again and again.

Two training stages

Stage 1 · 750 M moves44 %A tight move limit. It learned shallow cubes first, then began to solve fully scrambled ones.

Random test cubes solved at the end of each stage. The long limit from the very start did not help: it pays off only once the agent can solve some deep cubes.
